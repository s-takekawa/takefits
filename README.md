# Takefits

Takefits is an astronomical FITS file viewer and analysis tool developed by Shunya Takekawa.  
This is a minimal public pre-release version.

## Requirements
- Python 3.12 or later

## Setup
It is recommended to use a virtual environment:

```bash
python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py [path/to/fitsfile]
```
